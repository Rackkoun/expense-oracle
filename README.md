# 🔮 ExpenseOracle

**Intelligent Financial Insights via Local RAG**

ExpenseOracle is a privacy-first personal finance assistant that transforms raw bank data into actionable intelligence. By leveraging **RAG (Retrieval-Augmented Generation)** and local LLMs via **Ollama**, it provides deep analysis, anomaly detection, and budget optimization without your data ever leaving your machine.

---

## 🚀 Key Features
* **Automated Expense Classification:** Intelligent tagging of messy bank descriptions.
* **Anomaly Detection:** Identify unusual spending spikes or unexpected charges.
* **Predictive Cash-Flow:** Forecast your end-of-month savings based on historical patterns.
* **Credit Intelligence:** Track bank credits, including net/brut benefit analysis.
* **Privacy-Centric:** 100% local processing—no cloud subscriptions required.

## 🛠 Tech Stack
* **Orchestration:** [LangChain](https://www.langchain.com/) / [LlamaIndex](https://www.llamaindex.ai/)
* **LLM Engine:** [Ollama](https://ollama.com/) (Llama 3 / Mistral)
* **Frontend:** [Chainlit](https://chainlit.io/)
* **Vector Store:** [ChromaDB](https://www.trychroma.com/)
* **Data Processing:** Pandas & NumPy
